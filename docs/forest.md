# Обучение случайного леса

## Назначение
Бинарная классификация состояния пропеллера по вибрационным признакам.
Модель — ансамбль решающих деревьев
`sklearn.ensemble.RandomForestClassifier`, где итоговое решение
принимается голосованием по вероятностям деревьев.

## Описание логики обучения
1. Загрузка датасета и формирование векторов признаков через общий
   модуль `features.py` (46 признаков, окно 10 отсчётов, шаг 5).
2. Подготовка данных:
   - исключены полёты короче 1 с (обрубки);
   - выполнен undersampling класса «поломка» до числа нормальных
     полётов (39 на 39);
   - случайная перетасовка на `train/val/test` 70/15/15 со
     стратификацией по классу.
3. Подбор числа деревьев `n_estimators ∈ {10, 25, 50, 100, 200, 300, 500}`
   по F1 на валидации.
4. Подбор `max_depth ∈ {None, 5, 10, 15, 20}` при лучшем
   `n_estimators`.
5. Подбор `min_samples_leaf ∈ {1, 2, 5, 10, 20}` при лучших
   `n_estimators` и `max_depth`.
6. Финальная модель переобучается на `train + val` с выбранными
   параметрами и оценивается один раз на `test`.

## Архитектура модели
- Класс: `RandomForestClassifier`.
- Гиперпараметры:
  - `n_estimators` — подбирается;
  - `max_depth` — подбирается;
  - `min_samples_leaf` — подбирается;
  - `max_features = "sqrt"`;
  - `class_weight = "balanced_subsample"`;
  - `n_jobs = -1`;
  - `random_state = 42`.
- Размерность входа: вектор из 46 признаков.
- Выход: метка `0` или `1` и вероятность класса «поломка»,
  используемая для ROC-AUC.

## Полученные результаты
- Лучшее число деревьев по валидации: **25**.
- Лучшая глубина: **5**.
- Лучший `min_samples_leaf`: **1**.
- F1 на тесте (класс «поломка»): **0.998**.
- Precision: 0.996; Recall: 0.999.
- Accuracy: 0.999.
- AUC: **≈ 1.000**.

## Замечания
После балансировки оптимальное число деревьев заметно уменьшилось
(с 100 до 25), что говорит о хорошей разделимости классов в очищенных
данных. Лес даёт чуть более высокий recall (0.999), чем одно дерево,
при precision 0.996 и AUC ≈ 1.000.
