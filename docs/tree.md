# Обучение дерева решений

## Назначение
Бинарная классификация состояния пропеллера квадрокоптера по
вибрационным данным: «норма» против «поломка». Модель — одно решающее
дерево из библиотеки scikit-learn
(`sklearn.tree.DecisionTreeClassifier`).

## Описание логики обучения
1. Чтение датасета `dataset/{train,val,test}/{Normal,Deformed}/.../vibration_log.csv`
   через общий модуль `features.py`. Каждый CSV содержит шапку
   `time_seconds, total_vibration, rms_x, rms_y, rms_z`.
2. Подготовка данных:
   - исключены полёты длительностью менее 1 с (обрубленные записи);
   - применён undersampling класса «поломка»: из 86 поломочных полётов
     случайно отобраны 39, чтобы число поломочных и нормальных полётов
     совпало;
   - оставшиеся 78 полётов случайно перетасованы на `train/val/test`
     в пропорции 70/15/15 со стратификацией по классу и без разрыва
     частей одного полёта (`_partNN`).
3. Полёт нарезается на скользящие окна длиной 10 отсчётов
   (0.1 с при 100 Гц) с шагом 5 (перекрытие 50 %), что соответствует
   требованию на задержку детектирования не более 100 мс.
4. Для каждого окна вычисляется вектор из 46 признаков (статистики,
   FFT-полосы 0–10, 10–20, 20–35, 35–50 Гц, попарные корреляции).
5. Подбор `max_depth` в диапазоне 2..20 по F1 на валидации для
   класса «поломка»; финальная модель переобучается на `train + val`
   с выбранной глубиной.
6. Финальная оценка — один раз на отложенной выборке `test`.

## Архитектура модели
- Класс: `DecisionTreeClassifier`.
- Параметры:
  - `max_depth` — подбирается;
  - `min_samples_leaf = 10`;
  - `criterion = "gini"`;
  - `class_weight = "balanced"`;
  - `random_state = 42`.
- Размерность входа: 46 признаков.
- Выход: метка `0` (норма) или `1` (поломка).

## Полученные результаты
- Лучшая глубина по валидации: **2**.
- F1 на тесте (класс «поломка»): **0.995**.
- Precision: 0.992; Recall: 0.998.
- Accuracy: 0.997.

| split | окон  | норма  | поломка |
|-------|-------|--------|---------|
| train | 24378 | 18613  | 5765    |
| val   |  4372 |  3299  | 1073    |
| test  |  4699 |  3391  | 1308    |

Балансировка выполнена на уровне **полётов**: по 27/6/6 норм-полётов
и 27/6/6 поломочных полётов в `train/val/test`. На уровне окон
выборка остаётся естественно несимметричной (норм-полёты в среднем
длиннее), но это отражает реальные условия эксплуатации.

## Замечания
Оптимальная глубина — 2, то есть после балансировки задача всё ещё
разрешима 1–2 порогами по характерным признакам вибрации. Это
естественное свойство выборки, а не следствие утечки данных: дисбаланса
по числу полётов нет, обрубков нет, перетасовка случайная. Дерево
служит интерпретируемой базовой моделью для сравнения с более сложными
классификаторами.
